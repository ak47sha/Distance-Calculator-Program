# Distance Calculator

## Description
A simple Python program that converts distances entered in kilometers into miles using standard unit conversion formulas.

## How to Run the Program
Using Visual Studio Code (VS Code)
1. Open VS Code.
2. Click File > Open Folder... and select the folder where your .py file is saved.
3. Click on distance_calculator.py in the side menu to open it.
4. Click the Play button (triangle) in the top-right corner.
5. Enter your inputs directly in the Terminal tab that opens at the bottom.

## Input Needed
1. A numeric value representing distance in kilometers.
2. A text response "yes" or "no" to answer whether or not you want to continue converting more distances from kilometers to miles.

## Sample Output
Enter distance in kilometers: 47
Distance of 47.0 kilometers in miles is 29.204437 miles.
Do you want to convert another distance? (yes/no): no
Program ended.
